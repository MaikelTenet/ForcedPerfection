# Forced Perfection!

In einer Welt wo jeder Glücklich ist, kannst du da überhaupt du selber Sein? Hast du einen Freien Willen oder kann man nicht glücklich sein wenn man wahrlich Frei ist!

In meinem Text-Adventure "Forced Perfection!" kannst du diesen Fragen auf der Spur gehen. Erkunde eine kleine Stadt in der jeder Glücklich zu sein scheint. Es gibt keine Trauer, keine Probleme und keinen Grund irgendwas zu ändern. Was ist der Ursprung und gibt es vielleicht mehr dahinter, als nur eine gute Work-Life-Balance?

## Starte das Spiel

Das Spiel kann in eine einfache Java Datei erstellt werden. Dafür muss man einfach dieses Projekt im Terminal öffnen und den Kommand "./gradlew clean package" schreiben. Danach kann das Spiel mit dem Kommand "java -jar build/libs/text-adventure.jar" gestartet werden. Öffnen deinen Browser und öffnen die Adresse: "http://localhost:8080/Game.html" und der spaß kann beginnen.

Das Spiel funktioniert indem du eine Aktion schreibst und wenn nötig, danach noch ein Objekt mit dem du interagieren möchtest.

Falls man feststeckt kann man immer den "help", "tipp" oder "command" Kommand benutzen um seine Momentanen Optionen anzuschauen.

Jetzt solltest du alles wissen um das Spiel starten zu können. Viel Spaß!
